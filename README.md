# 芦笛 · RUMI / Rumi 365

这是一个以鲁米研究、诗歌阅读与内在探索为核心的中文网站。

## 当前结构

### 首页：鲁米研究与内在探索

首页围绕“从原典进入鲁米，从诗回到自己的生命”展开，包含：

- 认识鲁米
- 鲁米与沙姆斯
- 12 个精神主题
- 诗歌“研究 / 内在探索”双入口
- “读—停—照—问—听—活”六步阅读
- 7 / 21 / 40 天内在旅程原型
- RUMI LAB 鲁米研究室
- 诗歌数据库结构
- “这真的是鲁米说的吗？”辨伪入口

### /daily/：鲁米诗歌365

原有的“鲁米诗歌365”完整保留，继续提供：

- 中英双语每日阅读
- 日期自动映射
- 内在提问与当日练习
- 浏览器本地日记
- 学习记录
- 分享海报生成

原数据仍位于 `data/rumi-days.json`。

## 内容与研究原则

本站的长期方向不是做“鲁米金句站”，而是逐步建立可追溯的鲁米中文知识库。正式诗歌条目将尽可能标注：

- 原作与卷次
- 行号与版本
- 波斯文与转写
- 中文直译与诗译
- 英译比较
- 苏非传统与思想语境
- 核心意象
- 内在探索问题

核心原则：

> 不把鲁米从他的传统中带走，也不把鲁米锁死在他的时代里。

## 关于现有 365 数据

现有日课项目从 `365 Days with RUMI` PDF 中抽取英文条目。当前 PDF 文本层实际可抽取 335 个每日条目和 12 个月份题词，并非完整 365 个自然日条目。公开重发布原书摘录及译文前，应确认相应授权。
