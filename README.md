# 芦笛 · RUMI / Rumi 365

这是一个以鲁米研究、诗歌阅读与内在探索为核心的中文网站。

## 当前结构

### 首页：鲁米研究与内在探索

首页围绕“从原典进入鲁米，从诗回到自己的生命”展开，包含：

- 认识鲁米
- 鲁米与沙姆斯
- 12 个精神主题
- 诗歌“研究 / 内在探索”双入口
- “读—停—照—问—听—活”六步阅读
- 八道门内在探索系统 + 7 / 21 / 40 天路径
- RUMI LAB 鲁米研究室
- 诗歌数据库结构
- “这真的是鲁米说的吗？”辨伪入口

### /biography/：鲁米详尽传记

现有传记主线按史料层级区分“较可靠年代 / 学术重建 / 后世传说”，内容包括：

- 出生地与“巴尔赫 / 瓦赫什”问题
- 父亲巴哈丁与家族传统
- 西迁、拉伦德与科尼亚
- 布尔汉丁与长期苏非训练
- 阿勒颇、大马士革的宗教学术训练
- 沙姆斯之前的鲁米
- 1244 年沙姆斯相遇及后续离开
- 萨拉丁、霍萨姆丁与关键伙伴关系
- 《玛斯纳维》的共同创作语境
- 1273 年离世及梅夫列维传统的后续形成

### /thought/：鲁米思想

思想页以关系图而非“金句主题”梳理九条思想轴：

- 真一 / tawḥīd
- 爱 / ʿishq
- 心 / qalb
- 小我 / nafs
- fanāʾ / baqāʾ
- 伙伴关系 / ṣuḥba
- samāʿ / 倾听、音乐与身体
- 故事、惊奇与认知边界
- 归返生活与服务

### /poetry/：诗歌与意象数据库

当前首批建立 20 条可追溯《玛斯纳维》诗段，覆盖六卷，可按关键词、卷次、意象与主题筛选。每条数据包括：

- 出处、卷次、联数、译者
- 意境
- 核心意象
- 象征
- 比喻机制
- 文本与思想语境
- 内在探索问题

数据位于 `data/poetry-atlas.json`。后续继续补波斯原文、转写和不同英译 / 中译版本比较。

### /journey/：鲁米内在探索

内在探索从首页的简短原型升级为独立系统。核心不是“做完课程”，而是让诗歌成为进入生命经验的第三物：

- 八道门：倾听、辨认、照见、相遇、炼化、松开、惊奇、归返
- “此刻我在哪里？”处境式入口，而不是先选课程
- 每道门同时包含：对应诗歌、核心问题、身体觉察、自由书写、关系练习、生活微实验与边界提醒
- 八种基础实践：慢读、静默、意象驻留、自由书写、二人深听、身体聆听、关系之镜、生活微实验
- 二人深度聆听流程
- 7 / 21 / 40 天三种停留节奏
- 浏览器本地保存的私人书写与“曾在这里停留”记录
- 诗歌数据库与内在探索双向深链：研究一首诗后可直接进入对应探索，也可从探索返回原诗研究卡

数据位于 `data/inner-journey.json`。这些练习是基于鲁米文本与苏非主题的当代体验设计，不声称复原十三世纪的历史修法。

### /daily/：鲁米诗歌365

原有的“鲁米诗歌365”完整保留，继续提供：

- 中英双语每日阅读
- 日期自动映射
- 内在提问与当日练习
- 浏览器本地日记
- 学习记录
- 分享海报生成

原数据仍位于 `data/rumi-days.json`。

## V4 内容体验：把诗读进生命里

第四轮重点不再增加装饰，而是让“内在探索”成为与传记、思想、诗歌数据库并列的一条核心主线。设计原则：

- 不把鲁米诗歌直接翻译成现代心理学结论。
- 先由诗歌与意象打开经验，再进入身体、书写、关系与现实行动。
- “八道门”是循环入口，不是灵性等级。
- “完成”改为“曾在这里停留”，减少课程化、绩效化。
- 所有实践尽可能重新连接可追溯诗歌条目。
- 明确区分传统文本 / 苏非语境与本站当代体验设计。
- 内在探索不是心理治疗；对于超出个人承受范围的处境，鼓励寻求现实支持。

## V3 体验设计：夜色中的波斯花园

第三轮 UI / UE 统一为“夜色中的波斯花园”体验系统。视觉不以堆砌异域符号为目标，而让装饰承担进入状态、辨认主题和理解内容的功能：

- 靛蓝夜色、孔雀青、石榴红、旧金与羊皮纸构成主色系统。
- 塞尔柱 / 波斯几何、拱门、星盘与蔓延光晕作为克制的界面语法。
- 首页按“门槛 → 倾听 → 相遇 → 向内 → 求证”组织滚动旅程，并以细金线显示阅读进度。
- 传记、思想、诗歌分别使用石榴红、孔雀青、月白金砂作为主题强调色，但保留统一导航与阅读逻辑。
- 365 日课被设计为较安静的“每日仪式室”，突出一首诗、一个问题、一段私人书写。
- 深色区域负责营造神秘与进入感，长篇正文仍回到高对比度羊皮纸阅读面。
- 动画只用于微弱旋转、渐入与状态提示，并遵守 `prefers-reduced-motion`。
- 移动端继续执行“中文标题不孤字、不碎裂”的硬规则。

## 内容与研究原则

本站的长期方向不是做“鲁米金句站”，而是逐步建立可追溯的鲁米中文知识库。正式诗歌条目将尽可能标注：

- 原作与卷次
- 行号与版本
- 波斯文与转写
- 中文直译与诗译
- 英译比较
- 苏非传统与思想语境
- 核心意象
- 内在探索问题

核心原则：

> 不把鲁米从他的传统中带走，也不把鲁米锁死在他的时代里。

## 视觉与标题规范

这是本项目后续页面都应遵守的固定规则：

1. 标题优先保持一行，不为了制造“设计感”随意断句。
2. 确需换行时，只在逗号、顿号、冒号或明确语义单元之间断开。
3. 桌面端先通过合理字号、容器宽度和留白保证完整一行；移动端再按语义断行。
4. 中文标题必须完整、连贯、易读，避免一两个字孤零零落到下一行。
5. 页面避免纯文字堆叠。重要章节至少配置一处与内容相关的图像、图解或克制的动态视觉；动画不喧宾夺主。
6. 图片优先服务于理解：人物关系、生命地理、原典与版本、意象和实践路径，而不是只做装饰。

## 关于现有 365 数据

当前 `data/rumi-days.json` 中有 365 个日课条目，网站按自然日期映射展示。数据来源与译写仍需持续校勘；公开重发布原书摘录及中文译文前，应确认相应授权与出处。
