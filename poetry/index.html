当前收录 20 条核心诗段 · 覆盖六卷 · 持续扩充。这里的“数据库”不是把鲁米变成标签，而是让标签重新把你带回原诗。

先理解数据库的逻辑

意象不是密码，比喻也不是固定答案

同一个“火”，在不同诗段里可以是神圣之爱，也可以是欲望；同一个“酒”，既可能指精神陶醉，也可能在故事中就是世俗酒。真正重要的是：它在这一段里做了什么。

意境这段诗首先让人“进入”怎样的空间、声音、温度与动作。
象征某个形象在这一段中指向什么，不把它扩大成永远不变的词典释义。
比喻机制鲁米如何通过尺度、反转、拟人、悖论、故事或身体经验改变读者的观看。
语境它在故事、古兰经、苏非修行或整卷叙事里处于什么位置。
出处作品、卷次、联数、中文译者；后续逐步补波斯文、转写与版本比较。
内在探索问题不是“这句话教导我什么”，而是“它让我看见了什么”。

八组核心意象

一首诗，多个入口同一意象，也会变形

01REED · NAY

芦笛：被割离之后才发出的声音

它首先属于听觉。芦笛不是在“谈故乡”，而是在声音本身里携带失去故乡的痕迹。鲁米以此开启《玛斯纳维》。

核心动作：被割离 → 中空 → 被吹奏 → 发声。
02MIRROR · HEART

镜子：心不是制造真理，而是恢复反射

黑铁、铁锈、擦拭、澄清、映月——鲁米把心灵训练写成非常具体的工艺过程。

核心动作：蒙尘 → 研磨 → 澄明 → 映照。
03OCEAN · SOURCE

大海：从局部形态回到关系与源头

钵盂装不下海，泡沫不是海，水缸却可以与海相通。海洋意象不断调整“个体与整体”的关系。

核心动作：局部 → 看见尺度 → 接通 → 不再孤立。
04FIRE · TRANSFORMATION

火：同一种热，可能把人烧开，也可能把人烧窄

爱的火焰使芦笛发声，欲火却使人失去辨识。鲁米故意让“火”承担相反功能。

核心动作：加热 → 失去旧形 → 看它扩大还是吞噬生命。
05WINE · INTOXICATION

酒：惯常意识松动之后，谁在主导？

精神之酒、爱之酒、世俗酒不是一回事。醉意常用来描写理性边界松动，但必须看上下文。

核心动作：饮下 → 失控 / 超越 → 重新辨识。
06BIRD · CAGE

鸟与笼：自由不是“去哪儿”，而是能否活出本性

精神之鸟会在笼中感到局促；被家鸡养大的鸭子仍然渴望海。自由与“记得自己是谁”彼此相连。

核心动作：被困 / 被误养 → 记起 → 离笼 / 入海。
07GARDEN · WATER

花园：语言真正有生命时，会改变内在生态

鲁米常把心、雨水、溪流、花园串在一起。好的语言不是信息，而是让某种东西重新生长。

核心动作：干涸 → 被灌溉 → 发芽 → 开花。
08LIGHT · SEEING

光：争论有时不是观点问题，而是照明条件不同

黑屋大象最关键的不是“每个人都有道理”，而是：没有光时，每个人只能把触摸到的局部当成全部。

核心动作：黑暗 → 局部触摸 → 明烛 → 重新看整体。
